# Archived brief — Midas project room v2 (historical Kimi bake)

Implement **Midas v2**. Keep v1’s walnut/brass/green mood. Fix camera, agents, zoning.

## Camera

Elevated 3/4, 3D, **lower than v1**.

- Look-down **42°** from horizontal (v1 was ~52° — too steep)
- Perspective FOV **38**
- Distance ~14–16 so the floor plan reads (board, benches, couch all visible)
- WASD / arrows pan; Q/E yaw 15°
- **No pointer lock, no FPS**

## Zoning (must read as separate places)

1. **Orchestrator** — large blackboard / dry-erase wall with chalk-like task blocks. Agent **midas** works here.
2. **Builder** — workbench / keyboard pit with tools and a hot terminal. Agent **midas-cio** (or a builder) works here.
3. **Reviewer** — review desk with stacked pages + dual inspect screens, slightly apart. Agent **midas-risk** reviews here *or* name the reviewer clearly.
4. **Downtime** — leather couch + sideboard drink nook, **not** touching the work stations. One agent off-duty here.
5. Far-wall **door** back to Campus.
6. Optional extra Midas flavor: ticker strip, one research side-table — do not collapse 1–4 into one island.

Open toward the camera. Parquet or dark carpet. Warm practicals + cool screen fill. Fog. ≥12 props.

HUD / hologram in-room: **Midas** (the room name). Campus map is not this file.

## Agents — distinct aliens + name tags

Four agents, **four different alien species** (not humans, not identical capsules). Readable silhouettes from 3/4 view. More mesh than head+body: horns / frills / extra arms / tails / asymmetric heads / different materials. Quality over count.

| Name tag (exact) | Pose | Station |
|------------------|------|---------|
| `midas` | working | orchestrator board |
| `midas-cio` | working | builder bench |
| `midas-research` | working | reviewer desk (researching/inspecting) |
| `midas-monitor` | idle / seated | couch |

**Name tags:** CanvasTexture sprites (or equivalent) that **always face the camera**, above each head. Dark plate + light text. No unlabeled bodies.

Do **not** load extra Three.js addons. Only `three.min.js` r160. Tags = `THREE.Sprite` + canvas texture.
